# مكتب بن يحيى للعقارات — نسخة عرض (Vue 3 + Vite)

موقع عرض تجريبي ثنائي اللغة (عربي/إنجليزي) لمكتب بن يحيى للعقارات — شارع أم الحمام، الرياض.

## التشغيل
```bash
npm install
npm run dev
npm run build   # dist/
```
Vercel: Build `npm run build` — Output `dist`.

## الهوية
- من لوحة المكتب الجديدة: كحلي ملكي + أبيض، مع أخضر شعار «إيجار» الظاهر على اللوحة كلون ثانوي.
- شريط كحلي بأرقام المكتب يحاكي اللوحة الضوئية. خط Almarai (طابع سعودي) و DM Serif Display للإنجليزي.

## الأقسام
- **اطلب عقار**: (إيجار / أبي أأجّر عقاري / إدارة أملاكي) ← نوع العقار ← الحي ← عدد الغرف ← الميزانية السنوية (شريط) ← واتساب.
- **للملّاك**: تسويق وتأجير، عقود إيجار، تحصيل، صيانة.
- **كيف نشتغل** + **«ما لحقت ترد؟ نحن نتصل فيك»**: طلب معاودة اتصال بوقت مفضل — يعالج شكوى متكررة في المراجعات (عدم الرد على الجوال).
- آراء Google، المكتب (الدوام، الأرقام الأربعة، الخريطة).

## نقاط تُؤكَّد مع العميل
- الخدمات (إدارة أملاك، تحصيل، صيانة) مستنتجة من المراجعات وشعار إيجار — تُؤكَّد.
- قائمة الأحياء أمثلة قريبة من المكتب — تُعدَّل.
- لا عروض عقارية حقيقية في الموقع؛ يمكن إضافة قسم عروض يُدار من لوحة بسيطة لاحقاً (فرصة بيع إضافية).
- اللوحة تذكر «للمقاولات» — يمكن إضافة صفحة للمقاولات إذا رغبوا.
- موقعهم القديم biyahya.wuiltsite.com لا يعمل.
